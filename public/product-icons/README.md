Public favicons used to identify linked product websites. Product names and marks belong to their respective owners; links do not imply endorsement or affiliation.

- JSM / Atlassian: https://www.atlassian.com/favicon.ico
- Freshservice / Freshworks: https://www.freshworks.com/favicons/favicon-32x32.png

Flow uses the navigation wordmark supplied by the project owner from https://www.letsflow.ai/. Zendesk uses the SVG supplied by the project owner, rendered in a light color for the dark background.

The mark-only SVG variants use the supplied artwork with a cropped viewBox for consistent icon sizing. Original wordmarks remain alongside them.
