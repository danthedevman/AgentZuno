# Reporting security issues

Check the repository's [Security page](https://github.com/danthedevman/agentzuno/security) for a private vulnerability reporting option. If it is available, use it to report the issue privately. If it is unavailable, open an issue asking for a private reporting channel without publishing exploit details, credentials, or affected records.

Include the affected version or commit, deployment configuration, expected behavior, actual behavior, and a minimal reproduction using fictional data. Explain which roles or workspaces are involved. Remove secrets and personal information from logs and screenshots.

AgentZuno is under active development. Automated checks and code scanning do not certify production security. Review the [security documentation](docs/security.md) and [roles and features](docs/roles-and-features.md) before deployment. Reports concerning authorization, workspace isolation, uploads, workflow execution, credential handling, or either database adapter are especially useful.
